## 住所を組み立てる

トップページ（`/`）で操作します。

1. **地域を選ぶ**：左側の一覧から地域を選びます。一覧は「大阪市（24区）」「堺市（7区）」「その他の市」「町村」に分かれています。「地域名検索」に市区町村名を入力すると絞り込めます。日本語・ローマ字・郡名のいずれでも検索できます（例：`東淀川`、`堺`、`Toyonaka`、`三島郡`）。
2. **町名を指定する**：
   - 大阪市の区：町名を一覧から選びます。町名を選ぶと、その町の丁目が選択肢に表示されます。
   - それ以外の地域（「入力」の印が付いた地域）：町名と丁目を入力します。
3. **番・号を入力する（任意）**：番（街区符号）と号（住居番号）を入力します。
4. **「住所を表示」を押す**：「生成した住所」に結果が表示されます。

地域や町名を変更すると、それまでに選んだ丁目・番・号はリセットされます。

### 丁目がない町

大阪市の町には、丁目がない町があります（例：北区角田町）。この場合、丁目の欄は「丁目なし」と表示され、番・号だけを入力できます。

- 例：大阪市北区 → 角田町 → 丁目なし → 番 `5`・号 `15` → `大阪府大阪市北区角田町5-15`

`5-15` は「5番15号」であり、「5丁目15」ではありません。

一部の町（例：中央区上町）は、丁目のある住所とない住所の両方があります。この場合は「丁目なし」と各丁目のどちらも選べます。

### 配色の切り替え

ヘッダーのボタンで、ライト表示とダーク表示を切り替えます。選んだ配色はブラウザーに保存され、次に開いたときも同じ配色で表示されます。

## 入力の規則

### 大阪市の区

| 項目 | 規則 |
| --- | --- |
| 町名 | 一覧から選択（一覧にない町名は指定できません） |
| 丁目 | その町に登録された丁目から選択 |

### 堺市の区・その他の市町村

町名のデータを収録していないため、入力された町名が実在するかどうかは確認しません。形式のみを検査します。

| 項目 | 規則 | 例 |
| --- | --- | --- |
| 町名 | 漢字・ひらがな・カタカナで30文字以内。数字・記号・空白・「丁目」は含めない | `千里山西`、`東三国ヶ丘町` |
| 丁目 | 任意。1～99 の数字 | `3`・`３`・`3丁目` はいずれも `3丁目` になる |

次のような入力は受け付けません：町名に `千里山西5丁目`・`千里山西1`・英字・記号を含む、31文字以上の町名、丁目に `0`・`100`・`三`（漢数字）。

### 番・号（全地域共通）

| 規則 | 内容 |
| --- | --- |
| 桁数 | 1～6桁の数字 |
| 全角数字 | 半角に変換します（`５`・`１５` → `5-15`） |
| 先頭の 0 | 使用できません（`05` は不可） |
| 号だけの指定 | できません。号を入力する場合は番も入力してください |

番・号は形式のみを検査し、実在するかどうかは確認しません。

### 作成される住所の形

| 地域 | 形 | 例 |
| --- | --- | --- |
| 政令指定都市の区 | 大阪府 + 市 + 区 + 町名 + 丁目 + 番-号 | `大阪府堺市北区東三国ヶ丘町3丁目1-2` |
| 市 | 大阪府 + 市 + 町名 + 丁目 + 番-号 | `大阪府吹田市千里山西5丁目10-3` |
| 町・村 | 大阪府 + 郡 + 町村 + 町名 + 丁目 + 番-号 | `大阪府三島郡島本町桜井2丁目` |

## 郵便番号を調べる

ヘッダーの「郵便番号検索（API）」、または住所を表示したあとの「ポストくんで郵便番号を調べる」から開きます（`/PostalCode`）。

1. 地域を選び、「町名の指定へ進む」を押します。
2. 町名を指定します。大阪市の区は一覧から選び、それ以外の地域は町名を入力します。
3. 「郵便番号を検索」を押すと、候補が「検索結果」に表示されます。

### 検索について

- 公開 API「[ポストくん](https://postcode.teraren.com/doc)」を利用します。登録や API キーは不要です。
- 送信するのは**地域と町名だけ**です。丁目・番・号は送信しません。
- 都道府県・市区町村・町名が選んだ地域と一致する候補だけを表示します。別の地域にある同じ名前の町は表示しません。
- 郵便番号は町域単位の候補です。丁目・番・号ごとの郵便番号や、建物ごとの郵便番号には対応していません。
- 大阪市以外の地域では、入力した町名が API の町域名と完全に一致した場合だけ候補が表示されます。町名の実在を確かめる手段としても使えます。
- 該当なし、アクセス制限、通信エラー、タイムアウト（8秒）の場合は、画面に案内が表示されます。この場合も、住所の組み立てとダウンロードは通常どおり利用できます。
- ポストくんの仕様や利用条件は変更される場合があります。[利用規約](https://postcode.teraren.com/terms)を確認してください。

## JSON でダウンロードする

| ボタン | ファイル名 | 内容 |
| --- | --- | --- |
| 選択した住所を JSON で保存 | `osaka-address.json` | 表示中の住所1件 |
| 大阪府データを JSON でダウンロード | `osaka-address-dataset.json` | 府内43市町村の一覧（`municipalities`）と、大阪市24区の町名・丁目（`osakaCityWards`） |

ファイルは UTF-8 で出力されます。

### 住所1件の JSON の例

大阪市の区：

```json
{
  "prefecture": "大阪府",
  "county": null,
  "city": "大阪市",
  "ward": "東淀川区",
  "town": "大桐",
  "chome": "2丁目",
  "ban": null,
  "go": null,
  "formattedAddress": "大阪府大阪市東淀川区大桐2丁目",
  "localGovernmentCode": "27114",
  "townSource": "大阪市 区別町名一覧（収録データから選択）",
  "version": "0.6.0"
}
```

町・村（`county` に郡名が入ります）：

```json
{
  "prefecture": "大阪府",
  "county": "三島郡",
  "city": "島本町",
  "ward": null,
  "town": "桜井",
  "chome": "2丁目",
  "ban": null,
  "go": null,
  "formattedAddress": "大阪府三島郡島本町桜井2丁目",
  "localGovernmentCode": "27301",
  "townSource": "利用者入力（形式のみ検査）",
  "version": "0.6.0"
}
```

| 項目 | 内容 |
| --- | --- |
| `prefecture` | 都道府県（常に `大阪府`） |
| `county` | 郡名。町・村の場合のみ。市の場合は `null` |
| `city` | 市町村名 |
| `ward` | 区名。区のない市町村は `null` |
| `town` | 町名 |
| `chome` | 丁目。丁目なしの場合は `null` |
| `ban` / `go` | 番・号。未入力の場合は `null` |
| `formattedAddress` | 画面に表示された住所 |
| `localGovernmentCode` | 地方公共団体コード（5桁） |
| `townSource` | 町名の出典（収録データから選択したか、入力された値か） |
| `version` | 出力したアプリのバージョン |

## URL で直接指定する

画面を操作せずに、URL の指定だけで住所を表示・ダウンロードすることもできます。

| 目的 | URL の例 |
| --- | --- |
| 住所を表示 | `/Address/Index?area=大阪市北区&town=角田町&ban=5&go=15&mode=show` |
| 住所1件をダウンロード | `/Address/DownloadJson?area=大阪市東淀川区&town=大桐&chome=2丁目` |
| 大阪市外の住所をダウンロード | `/Address/DownloadJson?area=島本町&town=桜井&chome=2` |
| 府内データ一式をダウンロード | `/Address/DownloadDataset` |

| パラメーター | 内容 |
| --- | --- |
| `area` | 地域。`大阪市北区`・`堺市北区`・`豊中市`・`島本町` のように指定します |
| `town` | 町名 |
| `chome` | 丁目。大阪市の区は `2丁目` の形、その他の地域は `2` でも指定できます |
| `ban` / `go` | 番・号 |
| `mode=show` | 住所を表示した状態で画面を開きます（表示用 URL のみ） |

- `area` の代わりに区名だけを `ward=北区` のように指定した場合は、大阪市の区として扱います。堺市の区は `area=堺市中区` のように市名を含めて指定してください。
- 存在しない地域・町名・丁目や、規則に合わない値を指定すると、ダウンロード用 URL は `400 Bad Request` を返します。

## 設定

設定は `appsettings.json` にあります。パソコンごとに変えたい値や、パスワードを含む値は User Secrets で上書きしてください。

| 設定 | 既定値 | 内容 |
| --- | --- | --- |
| `AddressData:Source` | `Json` | 住所データの読み込み元。`Json` または `Database` |
| `AddressData:DataDirectory` | `Data` | 住所データ（JSON）のフォルダー。相対パスはアプリのフォルダーが基準 |
| `PostalCodeApi:BaseAddress` | `https://postcode.teraren.com/` | 郵便番号 API の接続先 |
| `PostalCodeApi:TimeoutSeconds` | `8` | 郵便番号 API の待ち時間（秒）。1～60 |
| `ConnectionStrings:OAMVC` | （空） | PostgreSQL の接続文字列 |
| `Database:MigrateOnStartup` | `false`（開発環境では `true`） | 起動時にテーブルと初期データを作成・更新するか |

- `AddressData:Source` を `Database` にした場合は、`ConnectionStrings:OAMVC` が必要です。未設定のときは起動しません。
- 設定値が不正な場合（存在しないデータフォルダー、範囲外のタイムアウト、接続できないデータベースなど）は、起動時にエラーとなり、アプリは起動しません。
- 住所データは起動時に読み込みます。データを変更した場合は、アプリを再起動してください。
- Docker を使わず、既存の PostgreSQL にデータベースを用意する場合は、`db/setup/create_database.sql` のパスワードを書き換えてから管理者ユーザーで実行します。

## データの出典と注意事項

| データ | 出典 |
| --- | --- |
| 大阪府の市町村一覧（43市町村・地方公共団体コード） | 大阪府「[住民基本台帳人口](https://www.pref.osaka.lg.jp/o040050/shichoson/juki/juki2012.html)」の市区町村一覧 |
| 大阪市24区の町名・丁目（580町名・1,815丁目） | 大阪市「[区別町名一覧](https://www.city.osaka.lg.jp/shimin/page/0000061040.html)」 |
| 郵便番号 | [ポストくん](https://postcode.teraren.com/)（検索時に取得） |

- 町名・丁目のデータは、公開情報をもとに手作業で構造化したものです。公式の住所マスタや住民基本台帳ではありません。
- 最新性・網羅性は保証しません。町名の変更などは、大阪市の公式の一覧と照らし合わせてください。
- 丁目が登録されていても、その丁目のすべての番・号が実在することを意味しません。
- 町名・丁目のデータを収録しているのは大阪市24区だけです。その他の地域の町名は、入力された値の形式のみを検査します。
- 大阪市の区の構成は、大阪都構想の住民投票の結果によって変わる可能性があります。変更された場合、収録データは実際の住所と一致しなくなります。
- 住所を業務などで利用する場合は、最新の公的データや住所 API と照合してください。
- 住所の登録・更新や、ユーザー認証の機能はありません。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 起動時に「区名が重複しています」などのデータのエラーが出る | 古いビルド結果が残っている可能性があります。`OsakaAddressMvc` と `OsakaAddressMvc.Tests` の `bin/`・`obj/` を削除してから、もう一度ビルドしてください |
| 郵便番号の検索で候補が出ない | 町名に丁目を含めていないか確認してください。大阪市外の地域は、町名が API の町域名と完全に一致する必要があります |
| 郵便番号の検索で接続エラーが出る | 時間をおいて再度お試しください。住所の組み立ては影響を受けません |
| `Database` に切り替えると起動しない | `ConnectionStrings:OAMVC` が設定されているか、`docker compose ps` でデータベースが起動しているか（`healthy`）を確認してください |
| 複数のサーバーで同時に起動する | `Database:MigrateOnStartup` を `false` にし、テーブルの作成・更新はデプロイ時に1回だけ行ってください。同時に実行すると競合する場合があります |
