## A. 自動／静的チェック（配布前に確認）

- `Data/Wards/` に各行政区の JSON が24ファイルあること。v0.5 以降のファイル名は `大阪市{区名}.json`（例：`大阪市北区.json`）で、各ファイルに `code`（地方公共団体コード）があること。
- JSON に `ward`・`sourceUrl`・`towns` があり、各区で町名の重複がないこと。
- 町名によって丁目の数が変わること（例：東淀川区大桐1～5丁目、天王寺区上汐3～6丁目）。
- jQuery 系ライブラリファイル・画面への script 参照がないこと。
- ダウンロード用の Controller アクションと色モード切替コードがあること。
- **実ビルドとブラウザーテストは現環境で未実施**。以下は利用者 PC で確認してください。

```powershell
Remove-Item Env:OSAKA_TEST_DB
```
