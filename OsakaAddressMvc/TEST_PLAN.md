# 動作確認の手順

自動テストの実行方法と、画面で確認する項目をまとめています。コマンドはリポジトリのルート（`OsakaAddress.slnx` がある場所）で、PowerShell を使って実行します。

## 1. 自動テスト

```powershell
dotnet test
```

Rider や Visual Studio では、テストエクスプローラーから `OsakaAddressMvc.Tests` を実行できます。

主に次の内容を確認します。外部の郵便番号 API には接続しません（応答は偽のデータで置き換えます）。

| 分類 | 確認する内容 |
| --- | --- |
| 地域データ | 43市町村・72地域が読み込まれること、大阪市北区と堺市北区を区別すること、ローマ字・郡名で検索できること |
| 住所の組み立て | 正しい入力から住所を作成すること、全角数字・丁目の表記を統一すること、郡名が付くこと |
| 入力の検査 | 号だけの指定、数字以外、7桁以上、先頭の 0、登録されていない町名・丁目、規則に合わない町名を拒否すること |
| データの検証 | 市町村や区の件数が足りない場合、区名が重複している場合に起動時エラーとなること |
| 郵便番号の検索 | 選んだ地域の候補だけを返すこと、重複を除くこと、該当なし・アクセス制限・サーバーエラー・不正な応答・通信エラー・タイムアウトを区別すること |
| データベースの準備 | テーブル作成と初期データのスクリプトが欠番なく揃い、件数が JSON と一致すること |

PostgreSQL を使う3件のテストは、接続先を指定しない場合「スキップ」になります。失敗ではありません。

## 2. PostgreSQL を使うテスト（任意）

PostgreSQL を使うテストは、環境変数で接続先を指定したときだけ実行されます。事前にリポジトリの [README](../README.md) の手順で PostgreSQL を起動してください。

| 環境変数 | 用途 | 指定するデータベース |
| --- | --- | --- |
| `OSAKA_TEST_DB` | 接続の確認 | 通常のデータベース（`oamvc`） |
| `OSAKA_MIGRATION_TEST_DB` | テーブル作成の確認、データベースと JSON の内容の一致 | **テスト専用の空のデータベース**（`oamvc_test`） |

```powershell
# テスト専用のデータベースを作成（初回のみ）
docker exec oamvc-postgres psql -U oamvc_user -d oamvc -c "CREATE DATABASE oamvc_test OWNER oamvc_user ENCODING 'UTF8'"

$env:OSAKA_TEST_DB = "Host=localhost;Port=5434;Database=oamvc;Username=oamvc_user;Password=..."
$env:OSAKA_MIGRATION_TEST_DB = "Host=localhost;Port=5434;Database=oamvc_test;Username=oamvc_user;Password=..."
dotnet test --filter "Category=Integration" --logger "console;verbosity=detailed"
Remove-Item Env:OSAKA_TEST_DB, Env:OSAKA_MIGRATION_TEST_DB
```

| No. | 確認内容 | 期待結果 |
| --- | --- | --- |
| 1 | 環境変数を指定せずに `dotnet test` | PostgreSQL を使うテストがスキップされ、ほかのテストは成功する |
| 2 | 環境変数を指定して上記のコマンドを実行 | すべて成功する。接続確認ではデータベース名・ユーザー・バージョンが表示される |
| 3 | 接続文字列のポート番号を誤った値にして実行 | 接続エラーで失敗する（確認後は元に戻す） |

- `OSAKA_MIGRATION_TEST_DB` には、ほかの用途のデータベースを指定しないでください。テストがテーブルを作成します。
- 接続文字列（パスワードを含む）はファイルに書かず、環境変数で渡してください。

## 4. 設定とデータの確認

各項目の確認後は、変更した設定やファイルを必ず元に戻してください。

| No. | 操作 | 期待結果 |
| --- | --- | --- |
| 45 | `appsettings.json` の `PostalCodeApi:TimeoutSeconds` を `0` にして起動 | 設定エラーで起動しない（元の値は `8`） |
| 46 | `appsettings.json` の `AddressData:DataDirectory` を存在しないフォルダーにして起動 | エラーで起動しない（元の値は `Data`） |
| 47 | `Data/Municipalities.json` から市町村を1件削除して起動 | データのエラーで起動しない |
| 48 | `Data/Wards/` の JSON を1件、拡張子を `.bak` に変えて起動 | データのエラーで起動しない |

`Data/Wards/` のファイル名を変えただけ（拡張子は `.json` のまま）では、起動は中止されません。区はファイル名ではなく、ファイルの中の区名で識別するためです。
